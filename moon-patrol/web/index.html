Moon Patrol

A port of the 1983 Atari, Inc. DOS conversion of Irem's 1982 arcade game. The screen model, palette and control map are the DOS version's, read out of the binary. Anything invented is noted in ../docs/04-porting.md.

click the game to start (any key also works)
F1 start game F2 option screen ←→ or AD drive Space or W jump Z shoot forward X shoot up M mute P pause

Drive right, shoot what you can, jump what you cannot. The buggy holds a fixed column in the game field; the moon scrolls past it. Rocks in front of the wheels are shot with Z. Craters are jumped with Space. UFOs overhead are shot with X. Reach checkpoints A through Z.

The palette is CGA mode 4, palette 1 — the four colours cyan, magenta, white on black — because that is the palette enter_cga_graphics at file 0x573 chooses at boot, and no other. The split between the fixed status bar and the scrolling field exists because the DOS program programs the CGA CRTC that way in program_crtc_split at file 0x85D.

What is not the DOS version's, and is documented as such: the physics of the jump, the exact spawn rates, the point values, the sound effects, and the sprite artwork. Those live in routines whose shape is read but whose values the reading does not settle. See docs/04-porting.md for the boundary.

Original DOS game © 1983 Atari, Inc.; arcade original © 1982 Irem. This port ships none of it — the artwork here is redrawn in the four-colour palette the original used.
