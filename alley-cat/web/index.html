Alley Cat

A reimagining of Bill Williams' 1984 game. Two screens rendered here — the title and the courtyard (phase 0) — keeping the shape of the CGA original but drawing everything procedurally at 3× the resolution, with lighting, animation, and colour the 1984 hardware could not give it.

What the original looked like

CGA mode 4: 320×200, four colours — magenta, cyan, white, black. The title screen showed a wooden fence with five trash cans, a tiny cat silhouette on the fence, and the game name in cursive script. Phase 0 was a sparse room: two chairs, a table, a small round table, a floor lamp, and a fireplace with a black opening.

Both frames are captured in reference/screens/; the reconstruction rebuilds byte-identically and every reference frame here came from the rebuild, not the shipped binary.

What this port changes

No file matches the original pixel for pixel. The arrangement is preserved — same furniture in the same places, same fence composition — but the palette is unshackled, the surfaces are shaded, the fireplace burns, the lampshade actually casts light, and the trash cans look like metal instead of stacked hoops.

Everything on the canvas is drawn from JavaScript. No image files, no external fonts loaded at runtime beyond the browser's own cursive fallback. Open index.html directly — no build step, no server.
